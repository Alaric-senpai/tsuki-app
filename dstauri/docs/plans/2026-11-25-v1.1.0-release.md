> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` (native execution in this session). Steps use checkbox (`- [ ]`) syntax for tracking. No background shells; run `cargo` in the foreground with a timeout.

**Goal:** Ship Tsuki `v1.1.0` from `Alaric-senpai/tsuki-app` with zero lint warnings, working Linux packages (`.deb`, `.rpm`, AppImage), corrected source/downloader bugs, AnimeCube disconnected and replaced by `animekhor.org`, and two new bulk download actions.

## Global Constraints

- Next.js is a static SPA: `output: 'export'`, `images: { unoptimized: true }`; no API routes/server actions/middleware/`next/image` optimization (AGENTS §4).
- All I/O lives in Rust commands; components never call `invoke` directly; server state via hooks → `lib/ipc/*` (AGENTS §6).
- TypeScript `strict`, no `any`, no unused exports; Rust `cargo fmt`, `cargo clippy -- -D warnings`, `cargo test` (AGENTS §11).
- Read legacy before porting; use real fixtures for parsers; never hand-edit generated bindings or `components/ui/*` (AGENTS §13).
- UI changes start from Stitch (MCP `get_screen({name:'projects/…'})` + `download_file`); tokens live in `docs/design/tokens.md` / `app/globals.css`.
- No secrets in the repo; keep `DISCLAIMER.md` visible in About.
- Commit + push after each phase/task group; conventional commit style.
- No background shells; `cargo` foreground with timeout. Keep untracked files unless asked otherwise.
- Linux is the dev platform; Windows/macOS must stay viable; keep diffs small and reviewable for the Termux workflow.

## Review Focus

| Input / failure mode | Expected behavior | Test that pins it (owning task) |
|---|---|---|
| Obsolete `/anime/pagg/2/` pagination link | Catalog page 2 loads; filters preserved | `catalog_url` paged assertion (Task 3) |
| Protocol-relative `//host/embed` or unsupported URL | Absolute URL sent to yt-dlp; real `ERROR:` shown as the banner with copyable console detail; no duplicate jobs | `absolute_media_url`, `ytdlp_error_line`, enqueue-dedup tests (Task 4) |
| Mini-player play on unsupported codec / before load | No unhandled rejection; non-blocking notice/toast | Vitest `play()` rejection test (Task 5) |
| “Clear queue” vs “Cancel downloads” | Clear removes only non-running rows and prevents restart resurrection; Cancel stops active jobs but keeps their terminal snapshot | queue pure-helper + SQL status-reset tests (Task 8) |
| Version/tag drift across tauri.conf/Cargo/package/UI | All surfaces say the same version; tag matches `release.yml` | version-consistency grep in Task 1 + Task 10 checklist |
