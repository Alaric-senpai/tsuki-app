# Changelog

All notable changes to Tsuki are documented here. This file is included verbatim
in the release notes generated by `.github/workflows/release.yml`, and is also
shown by the in-app update dialog.

## [1.1.2] — 2026-11-26

### Fixed

- **DonghuaStream browsing:** pagination now loads the real next page of series instead of repeating the same cards; `has_more` follows the site's pagination links.
- **animekhor:** selecting a genre and advancing pages now returns different results, and series detail pages open from catalog cards instead of returning HTTP 404 for the numeric `rel` id.
- **Explore detail screens:** the `/item` route now maps the source to a source-specific detail component, keeping the same UI while using the correct id/URL handling for each source.
- **RPM packaging:** `yt-dlp` and `ffmpeg` are installed as private `tsuki-` prefixed sidecars, so they no longer collide with Fedora's system packages (fix shipped in v1.1.1-hotfix.1).

### Added

- **Library filters:** sort and filter by name (A–Z/Z–A), date added and status in addition to the existing tag/status chips. Filter, search, sort, page and page-size selections are restored from localStorage on the next launch.
- **Automatic update checks:** enabled by default. When a newer release is found, a changelog dialog offers **Start update** and **Skip for now**, plus a checkbox to opt in or out of automatic checks and background downloads. These preferences can also be changed in Settings.
- **CI/CD:** all gates now run for PRs to `main` and `1.1.2`; a single aggregate **All checks** gate is suitable for branch protection, and releases require a successful CI run for the tagged commit.

### Notes

- Streamplay embed support is still under investigation in `reports/stplay.md` and is **not** shipped in 1.1.2.
- Release targets remain Windows (NSIS) and Linux (AppImage, deb, rpm); macOS/darwin jobs are skipped.
